# Data6 Games - Website Project

Sitio web oficial y portfolio interactivo para **Data6 Games**, centrado en el desarrollo de videojuegos independientes.

## 📁 Estructura del Proyecto

```
data6-games/
├── index.html          # Estructura principal HTML
├── css/
│   └── styles.css      # Estilos personalizados y efectos de neón
├── js/
│   ├── games-data.js   # Base de datos de videojuegos (JSON/Array JS)
│   └── main.js         # Lógica interactiva y renderizado de filtros
└── README.md           # Documentación del proyecto
```

## 🚀 Cómo ejecutar

1. Descarga y extrae el archivo ZIP.
2. Abre `index.html` en tu navegador web (o utilízalo con **Live Server** en VS Code).
3. ¡Listo! Puedes agregar más juegos editando directamente `js/games-data.js`.
